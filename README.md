# WIKA PPF — Website

Marketing website for **WIKA PPF**, the premium paint protection film brand. It's built with React, TypeScript and Vite and is **prerendered to static HTML**. Every page ships with full content, meta tags and structured data, so search engines can index it without running JavaScript. The site is hosted on GitHub Pages and has no backend.

## Quick start

```bash
npm install
npm run dev        # local dev server → http://localhost:5173
npm run build      # production build → /dist (prerenders every page)
npm run preview    # preview the production build → http://localhost:4173
```

## Before going live, edit these

| What | Where |
| --- | --- |
| Domain, email, phone, WhatsApp, address, socials | `src/config/site.ts` |
| Custom domain for GitHub Pages | `public/CNAME` (must match `site.url`) |
| Product specs, features, FAQ, partner text | `src/data/content.ts` |
| Guide articles (SEO blog) | `src/data/guides.ts` |
| Page titles & meta descriptions | `src/seo/meta.ts` |

> The specs marked "typical" (thickness, roll size, layer thickness) are industry-typical values. Confirm them against your official data sheets.

## Images

Raw photos live in `/data`. Real car photography from Unsplash is in `/data/stock`, with credits in `data/stock/CREDITS.md`. `npm run optimize-media` crops and resizes everything into responsive WebP files in `public/images`, writes `src/data/media.json`, regenerates `public/og-image.jpg`, and builds the before/after compare pair (`scripts/make-compare.mjs`). The compare pair is made from a single real photo, so both sides line up exactly. To add a photo, add an entry in `scripts/optimize-media.mjs`, run the script, then use `<Img name="your-slug" alt="…" />`.

To show a factory video on the Manufacturing page, put an `.mp4` in `public/media/` and set `factoryVideo` in `src/config/site.ts`.

Icons and the logo PNG are generated by `node scripts/make-icons.mjs`.

## Deploy to GitHub Pages (custom domain)

1. Create a GitHub repository and push this project to the `main` branch.
2. In the repository, go to **Settings → Pages → Build and deployment** and set Source to **GitHub Actions**.
3. Every push to `main` builds and deploys automatically (`.github/workflows/deploy.yml`).
4. Custom domain: in **Settings → Pages**, enter your domain and enable **Enforce HTTPS**. At your DNS provider, add:
   - `www` → CNAME → `<your-github-username>.github.io`
   - apex (`@`) → A records `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`

## SEO checklist after launch

- Add the site to **Google Search Console**, verify the domain, and submit `https://<your-domain>/sitemap.xml`.
- Add the site to **Bing Webmaster Tools**, which also feeds DuckDuckGo and Yahoo.
- Create a **Google Business Profile** for the company, and link back to the site from social profiles.
- The brand name "WIKA" alone is dominated by WIKA Alexander Wiegand, a measurement-instruments company. That's why the site consistently targets **"WIKA PPF"**, **"Wika paint protection film"** and **"Wika Germany PPF"**. Use those exact phrases on social media, packaging and listings so Google connects them to this site.

## Structure

```
src/
  config/site.ts        ← contact details & domain
  data/                 ← all website copy (products, FAQ, guides, media manifest)
  seo/meta.ts           ← per-page titles, descriptions, JSON-LD structured data
  components/           ← layout + interactive pieces (compare slider, self-heal demo, layer stack…)
  pages/                ← one file per page
  styles/               ← design system (tokens, layout, sections)
scripts/
  prerender.mjs         ← renders each route to static HTML + sitemap.xml + robots.txt
  optimize-media.mjs    ← photo pipeline
  make-icons.mjs        ← favicon / app icons / logo.png
```
